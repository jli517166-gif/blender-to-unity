# 变更记录

## 1.0.002

- 修复 Unity 2022+ 中 `ModelImporter.importMaterials` 已移除导致的编译错误。
- 修复 Unity 2022+ 中材质重映射类型需要使用 `AssetImporter.SourceAssetIdentifier` 的兼容问题。

## 1.0.001

- 创建中文 Blender 插件“木云 - Blender 到 Unity FBX”。
- 增加 Unity 版本选择：自动、2019、2020、2021、2022、2023、Unity 6。
- 增加 FBX 导出范围、修改器、三角化、切线、动画、骨骼选项。
- 增加贴图复制、材质清单生成、Unity 导入辅助脚本自动安装。
- 增加 Blender 后台自动化烟测脚本。
