# 木云 Blender 到 Unity FBX 插件验证说明

版本：1.0  
维护者：muyun  
最终打包编号：1.0.002

## 最终文件

- `muyun_blender_to_unity_fbx_addon_v1.0.002.zip`：Blender 可直接安装的插件包。
- `muyun_blender_to_unity_fbx_project_v1.0.002.zip`：完整源码、Unity 导入脚本、文档和测试脚本包。

## 已验证项目

- Blender 5.1.2 后台加载插件源码并导出测试 FBX：通过。
- Blender 5.1.2 从 zip 安装并启用插件：通过。
- 导出结果包含 FBX、贴图目录、`.muyun_unity.json` 材质清单和 Unity 导入脚本：通过。
- Unity 2022.3.22f1 批处理导入：脚本编译通过，FBX 导入通过，生成材质并绑定基础贴图和法线贴图。
- Unity 6000.3.12f1 批处理导入：脚本编译通过，FBX 导入通过，生成材质并绑定基础贴图和法线贴图。

## 说明

FBX 会配合贴图目录和材质清单一起使用，以降低 Unity 不同版本对 FBX 内嵌贴图解析不一致造成的数据丢失风险。复杂 Blender 节点材质、程序纹理和几何节点材质建议先烘焙成图片贴图再导出。
